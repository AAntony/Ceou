LES CHIFFRES OBSERVÉS

Un point de départ fiable.

Saisis les postes de tes factures ou importe le modèle Céoù. N’ajoute jamais à la fois une facture totale et son détail.

Utilisation du mois sélectionné

Laisse vide ce qui est inconnu. Utilise la même période que les dépenses. Les utilisateurs actifs sont des comptes distincts, pas le nombre d’inscrits.

Ajouter une dépense

Montant hors taxes après remises ; un avoir est négatif. Pour une facture commune à plusieurs projets, renseigne uniquement la part de Céoù. Les coûts fixes sont mensualisés manuellement.

Journal du mois

Format Céoù uniquement. Les CSV fournisseurs bruts et les PDF ne sont pas interprétés automatiquement. Chaque référence identique est ignorée ; un conflit bloque l’import entier.

Comment remplir le modèle CSV ?

Une ligne par poste et mois : id = référence unique ; month = AAAA-MM ; provider = fournisseur ; category = voice, photo, ai, hosting, storage, network, tools ou other ; kind = fixed ou variable ; amount = montant HT après remises ; currency = EUR, USD ou GBP ; eur_rate = valeur en euros d’une unité de la devise (1 pour EUR) ; note = origine du chiffre. Séparateur virgule ou point-virgule, encodage UTF-8. Les avoirs sont négatifs.

LES DOCUMENTS À RÉUNIR

De la facture au bon tarif.

Commence par le dernier mois complet et le mois en cours, séparément. Aucun mot de passe ni clé API n’est nécessaire.

01

Google · Gemini

Google Cloud → Facturation → compte concerné → Tableau des coûts / Cost table. Sélectionne le mois et le projet associé à Céoù, puis télécharge le CSV.

Conserve projet, service, SKU, coût, remises/crédits, devise et période. Joins le PDF ou relevé pour rapprocher le total. Une recharge prépayée n’est pas une consommation : utilise les coûts consommés.

Dans Google AI Studio → Dashboard → Usage, relève aussi les requêtes et consommations par modèle disponibles, pour la même période. Si aucun export n’est proposé, un relevé des valeurs suffit.

02

Supabase

Dashboard → organisation de Céoù → Billing → factures. Télécharge le PDF du dernier cycle complet et relève la facture à venir pour le cycle actuel.

Dans Usage, relève les utilisateurs actifs mensuels (MAU), le stockage, les transferts et les fonctions Edge. Note les dates exactes du cycle, qui peuvent différer du mois civil.

Une facture d’organisation peut regrouper plusieurs projets. Distingue la part de Céoù et les coûts de test. Le MAU de facturation est un indicateur d’activité authentifiée, pas une mesure exacte de rétention.

04

Autres frais & sauvegardes

Rassemble les factures Expo/EAS si tu paies un forfait, du domaine et des autres outils utilisés pour Céoù. Répartis un abonnement annuel sur douze mois.

Plus tard, les rapports de ventes et remboursements du magasin permettront de remplacer les hypothèses de recettes. Pour l’instant, le simulateur ne prétend pas connaître tes revenus.

Import : reporte les postes HT dans le modèle CSV Céoù ou le formulaire. Les PDF restent des justificatifs ; ne cumule pas totaux et détails.

La restauration remplace les données locales après confirmation. Une sauvegarde contient aussi tes hypothèses financières : garde-la privée.

Où vivent mes données ?

Sur cet ordinateur, dans le stockage local de ce navigateur, à l’adresse http://127.0.0.1:8094. Ouvre toujours cette même adresse. Une autre adresse, un autre navigateur ou l’effacement de ses données donne un espace séparé ou vide.

Le serveur n’écoute que sur cet ordinateur. Aucun fichier financier n’est envoyé à GitHub, à Céoù ou à un fournisseur. Le bouton de sauvegarde permet de télécharger tes données ; le tableau de bord ne les écrit pas dans le dépôt du projet.

Avec Céoù, les décisions se prennent sur des chiffres. Les cases vides restent vides.
